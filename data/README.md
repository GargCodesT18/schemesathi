# SchemeSathi Curated Schemes Database

This directory contains verified government scheme data for **SchemeSathi**.

## Provenance and Integrity Policy
1. **Official Sources Only**: Every scheme entry originates from verified Indian central or state ministry portals (e.g., `pmkisan.gov.in`, `nsap.nic.in`, `scholarships.gov.in`, `pmaymis.gov.in`).
2. **Deterministic Rules**: Eligibility criteria are stored in a machine-evaluable format with unambiguous operators (`equals`, `in`, `greater_than_or_equal`, `less_than_or_equal`, etc.).
3. **No Fabricated Rules**: Criteria mirror official statutory guidelines rather than speculative LLM assumptions.
4. **Regular Verification**: The `last_verified` field records the latest audit date against live government notification gazettes.

## Sectors Covered
- **Agriculture**: PM-KISAN, PM Kisan Maandhan Yojana, Punjab Crop Loan Waiver
- **Housing**: PM Awas Yojana - Gramin, PM Awas Yojana - Urban
- **Women & Child**: PM Ujjwala Yojana, Sukanya Samriddhi Yojana
- **Senior Citizens**: Atal Pension Yojana, Indira Gandhi National Old Age Pension Scheme
- **Employment & Vendors**: PM SVANidhi (Street Vendors)
- **Entrepreneurship**: Pradhan Mantri Mudra Yojana
- **Education**: Centrally Sponsored Post Matric Scholarship Scheme
